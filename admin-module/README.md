# AgriNex - Platform Governance & Admin Module

State-wide agricultural governance, Mandi board rate monitoring, dispute settlement, and KYC authorization interface.

### Features
- **Escrow Settlement Queue:** Authorize payment release upon delivery confirmation.
- **KYC Authorizations:** Verify farmer land records and buyer GSTIN credentials.
- **Mandi Price Indices:** Real-time state-wide price tracking and market intelligence.
- **Dispute Resolution:** Arbitration tools for quality mismatches and claims.
