# AgriNex - Logistics & Fleet Transit Module

Dedicated logistics, dispatch, and digital Proof of Delivery (e-PoD) interface for fleet transit operators.

### Features
- **Fleet Dispatch Manager:** Track active vehicle dispatches and capacity.
- **GPS Milestone Checkpoints:** Real-time route tracking and telemetry.
- **Proof of Delivery (e-PoD):** Digital handover confirmations triggering escrow clearance.
- **Freight Settlement:** Direct settlement of transport earnings.
