# AgriNex - Buyer & Mill Procurement Module

Dedicated procurement and bulk farm sourcing interface for verified buyers, mills, and food processors.

### Features
- **Live Marketplace Lots:** Browse active farm harvest lots from verified farmers.
- **Direct Bidding Engine:** Submit floor bids with automated escrow lock.
- **Quality Grade Filter:** Inspect Grade A/B/C certifications.
- **Inbound Fleet Tracker:** Track delivery transit status in real time.
